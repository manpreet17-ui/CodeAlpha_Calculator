Calculator Web Application

Overview

The Calculator Web Application is a responsive front-end project developed using HTML, CSS, and JavaScript. It performs basic arithmetic operations through an intuitive and user-friendly interface, providing a smooth and efficient calculation experience.

Features

- Addition, Subtraction, Multiplication, and Division
- Clear and Delete Functions
- Responsive Design
- Interactive User Interface
- Real-Time Calculation Display
- Keyboard-Friendly Layout

Technologies Used

- HTML5
- CSS3
- JavaScript
